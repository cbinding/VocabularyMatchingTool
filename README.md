# Vocabulary Matching Tool (VMT)
The Vocabulary Matching Tool is intended to aid in the creation of mappings from controlled vocabularies to the Getty Art & Architecture Thesaurus (AAT). The application presents source and target concepts side by side along with associated contextual metadata to facilitate more informed mapping decisions. The set of mappings developed may then be exported to RDF or delimited text (CSV) formats for archival and for use in other applications.

The application is deployed to [https://cbinding.github.io/VocabularyMatchingTool/](https://cbinding.github.io/VocabularyMatchingTool/)
